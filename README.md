# Laboratorio OOA - Sistema MSGF

Este repositorio contiene el desarrollo de los diagramas UML correspondientes al laboratorio de Análisis y Diseño Orientado a Objetos para el sistema de la **Fundación MSGF**.

El sistema tiene como objetivo principal estimar los fondos disponibles para otorgar hipotecas (calculado a partir de los ingresos por inversiones menos los gastos). Además, en la segunda iteración, se incorpora el módulo de gestión de **Becas-Crédito** para estudiantes universitarios.

## Estructura del Repositorio

Toda la documentación y los archivos editables de Draw.io se encuentran en la carpeta `docs`:

*   **`docs/iteración 1`**: Contiene los diagramas iniciales del sistema (Puntos 1 al 4).
*   **`docs/iteración 2`**: Contiene los diagramas actualizados con el nuevo requerimiento de Becas-Crédito (Punto 5).

## Herramientas utilizadas
*   Draw.io (diagrams.net) para el modelado UML.
*   Git y GitHub para el control de versiones.
