
# Iteración 1 - Sistema MSGF

## Resumen del Problema
La Fundación MSGF requiere un software para estimar los fondos disponibles destinados al préstamo de hipotecas. Este capital se calcula sumando los ingresos totales (los cuales provienen de inversiones y otras fuentes) y restándole los gastos operativos de la fundación. Adicionalmente, se requiere un reporte semanal que muestre los fondos disponibles para otorgar dichas hipotecas.

## Diagramas Incluidos en esta Iteración
En esta carpeta se encuentran los archivos `.drawio` con los siguientes entregables:
1.  **Diagrama de Casos de Uso (CDU):** Interacciones principales del Empleado MSGF con el sistema.
2.  **Diagrama de Clases Inicial:** Estructura estática (Activo, Hipoteca, Inversión y la clase MSGF).
3.  **Diagrama de Máquinas de Estado:** Modelado dinámico del bucle de ejecución del sistema.
4.  **Diagrama de Clases Límite y Control:** Arquitectura ECB inicial (Interfaz, Control y Entidades).
